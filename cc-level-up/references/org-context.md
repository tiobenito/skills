# Org Role Context

This file maps roles to personalized starter content. **Customize it for your own organization** —
replace the roles, sample CLAUDE.md flavor, and suggested skills below with ones that fit your team.

## Role Definitions (examples — replace with your own)

### Operations Coordinator

**CLAUDE.md flavor:**
- "I'm an Operations Coordinator. I process orders, handle documentation, and coordinate with partners daily."
- Key preferences: concise status updates, metric-first summaries, action items in bullet format

**Suggested first skills:**
- "Format my status report" — Takes raw notes and produces a clean daily/weekly status update
- "Extract key data" — Pulls key fields from messy emails or docs

**Suggested references:**
- Status report template, contact list, terminology glossary

---

### Operations Manager

**CLAUDE.md flavor:**
- "I'm an Operations Manager. I oversee team execution, handle escalations, and report on metrics."
- Key preferences: team-level summaries, escalation clarity, data-backed recommendations

**Suggested first skills:**
- "Weekly team summary" — Aggregates team updates into a manager-level report
- "Escalation template" — Structures an escalation with context, impact, and ask

**Suggested references:**
- SOP library, team roster, KPI definitions

---

### Sales

**CLAUDE.md flavor:**
- "I'm on the Sales team. I build client proposals, analyze opportunities, and manage accounts."
- Key preferences: client-facing polish, data in tables, persuasive but honest tone

**Suggested first skills:**
- "Draft client proposal" — Creates proposal sections from account notes
- "Competitive analysis" — Structures a comparison for a prospect

**Suggested references:**
- Proposal template, client profile format, pricing summary

---

### Data / Analytics

**CLAUDE.md flavor:**
- "I'm on the Data team. I build analyses, write SQL queries, and create dashboards."
- Key preferences: code in fenced blocks, explain methodology before results, reproducible outputs

**Suggested first skills:**
- "Format analysis output" — Turns raw query results into a clean report
- "SQL helper" — Helps write and explain SQL queries

**Suggested references:**
- Key table schemas, metric definitions, common query patterns

---

### Finance

**CLAUDE.md flavor:**
- "I'm on the Finance team. I handle invoicing, reconciliation, and financial reporting."
- Key preferences: precise numbers (no rounding unless asked), tabular format, audit-trail clarity

**Suggested first skills:**
- "Format invoice summary" — Extracts and organizes key fields from invoices
- "Reconciliation helper" — Matches and flags discrepancies

**Suggested references:**
- Chart of accounts, vendor list, monthly reporting template

## How This File Is Used

During Level 0 setup, the skill asks "What's your role?" and uses this file to:
1. Pre-fill the CLAUDE.md with a role-appropriate description
2. Suggest the most relevant first skill to build
3. Recommend starter reference documents

The user's own words always override these defaults — this is a starting point, not a prescription.
**Edit this file to match your organization's actual roles and content.**
