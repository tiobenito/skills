# CLAUDE.md Starter Template

## Questions to Ask First

1. "What's your role?" (maps to org-context.md for flavor)
2. "What do you use Claude for most?" (shapes the key preferences section)
3. "Any formatting preferences?" (bullet points vs prose, tables vs lists, concise vs detailed)

## Template (10-15 lines)

```markdown
# [Project Name]

## About Me
[Role description — 1-2 sentences from their own words, enriched with org-context.md]

## What I Use Claude For
- [Primary use case from their answer]
- [Secondary use case if mentioned]

## How I Like Things
- [Format preference — e.g., "Keep responses concise with bullet points"]
- [Tone preference — e.g., "Professional but conversational"]
- [Any specific rule — e.g., "Always show data in tables"]
```

## Tips for the Skill

- Use the user's exact words where possible — don't over-polish
- Keep it under 15 lines. They can always add more later
- Don't add sections they didn't mention (no placeholder sections)
- If they mention something they never want, add it: "Never: [thing]"
