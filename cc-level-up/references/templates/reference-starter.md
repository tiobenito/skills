# Reference Doc Starter Template

## Questions to Ask First

1. "What docs do you find yourself pasting into Claude over and over?" (these become references)
2. "What should Claude already know about your work?" (glossaries, lists, templates)

## Template

```markdown
# [Document Title]

[Brief description of what this reference contains and when Claude should use it.]

---

[Content organized with clear headers, tables, or lists. Keep it scannable.]
```

## Tips

- Reference docs are things Claude looks up, not instructions it follows
- Good references: glossaries, templates, contact lists, process docs, schemas
- Keep each doc focused on one topic
- Use tables and headers for scannability
- Update when the source of truth changes
